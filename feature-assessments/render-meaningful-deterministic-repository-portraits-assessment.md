# Assessment: Render meaningful deterministic repository portraits

## Decision

**ACCEPT as Stage 3, dependent on Stage 2.** This completes the smallest meaningful
Git-only product after the operational spine and factual analysis are proven.

## Claim / reality verification

| Claim from the vision | Live repository reality | Planning effect |
|---|---|---|
| Different histories should yield recognizable plants | Expected traits exist for five fixtures; no renderer exists | Encode semantic assertions and reviewable snapshots |
| SVG is authoritative | ADR 0001 and SvgProvenanceV1 say so | Exact SVG bytes and provenance are deterministic gates |
| Botany must be decoupled from rendering | BotanicalSceneV1 exists; no interpreter exists | Persist and test botanical JSON before geometry |
| Output must be inspectable | Source refs exist in contracts; no UI exists | Add legend and source/metric inspection to the viewer |
| A real prototype is required | Anthesis has Git history but no generated artifact | Publish its own portrait as the real-repository proof |

## Impact and contract safety

The stage consumes all three frozen contracts and extends behavior within their
declared values. A future forge-enriched provider, new renderer, or breaking grammar
requires separate intake and any genuinely new seam requires a new contract.

## Deferrals

GitHub enrichment, PNG/video, art-style plugins, bouquet, herbarium, timelapse, and
the declined helper bot remain outside the initial backlog.
