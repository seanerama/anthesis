# 0009. Select archetypes from neutral phenotype rules

- **Status:** Proposed
- **Date:** 2026-08-03

## Context

One plant habit cannot express steady, raceme-like high-release, and branch-heavy histories. Random species selection would be decorative and could imply qualitative judgments about repositories.

## Decision

Define archetypes as composable structural trait recipes selected from versioned, explainable phenotype rules. Begin with Aster; add Lupine for compressed rhythmic episodes and Vine for branch-heavy/irregular histories only after the shared prototype passes. A stable hash breaks exact rule ties. Decorative seed never chooses archetype. Explanations use descriptive axes and never rank health, merit, or quality.

## Alternatives considered

- One infinitely parameterized archetype reduces selection complexity but yields weak silhouette families.
- Random species maximizes novelty but disconnects form from history.
- A large species catalog front-loads decorative breadth before geometry quality.

## Consequences

Archetypes create meaningful silhouette variation while retaining explainability. Rule/version changes affect authoritative output and therefore require a grammar-version change.
