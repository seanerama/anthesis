# Stage 7 blind-recognition evidence

The five-person blind-recognition acceptance condition requires human observations and is intentionally not represented as an automated pass. No qualifying responses had been recorded when Stage 7 was built.

## Fixed protocol

Show each participant the annotation-free pinned-Chromium Botanical Plate portrait, without the product name, repository context, legend, contact sheet, or Git explanation. Ask only: “What does this image depict?” Record the response verbatim before any follow-up. A response counts when it independently names a plant, flower, flowering plant, or botanical illustration. Record participant identifiers as anonymous `viewer-1` through `viewer-5`, the portrait geometry hash, renderer/style versions, response, result, and UTC collection date below. Do not replace responses after seeing the result.
