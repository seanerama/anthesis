# Botanical Grammar v2

This package is the builder-ready design for replacing Anthesis's primitive visual grammar while preserving its deterministic Git-to-SVG spine.

- [Architecture assessment](architecture-assessment.md): repository evidence and final replacement decision
- [Specification](specification.md): summarization, phenotype, morphology, geometry, composition, style, and traceability
- [Schema proposal](schema.md): TypeScript-oriented persisted and in-memory interfaces
- [Implementation plan](implementation-plan.md): runnable increments, tests, fixtures, risks, and acceptance gates
- [Prototype recommendation](prototype-recommendation.md): the smallest art-direction proof

Consequential decisions are recorded in ADRs 0004–0010 under `docs/adr/`.
